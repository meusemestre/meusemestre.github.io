MEU SEMESTRE 3.5 — BUSCA GLOBAL REFINADA

Esta atualização mantém os recursos da versão 3.5 e aprimora somente a experiência visual da busca global no cabeçalho.

O que mudou:
- O campo de busca se expande suavemente ao receber foco.
- O contorno interno azul do campo foi removido.
- Ícone, borda e realce recebem transições suaves.
- A lista de resultados aparece com animação discreta e entrada escalonada.
- Ajustes responsivos para telas menores e suporte a preferência por movimento reduzido.

Como atualizar:
1. Faça uma cópia de segurança dos seus dados como precaução.
2. Extraia este pacote.
3. Substitua o index.html na raiz do repositório GitHub pelo novo index.html.
4. Faça o commit e aguarde a publicação do GitHub Pages.

Não apague os dados do navegador. Esta atualização não altera as regras do Firebase nem o formato dos dados acadêmicos.
